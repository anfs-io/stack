# containers

Container definitions for pcm, the Personal Container Manager. How they are laid out, overridden
and validated is in [pcm's README](https://github.com/anfs-io/system/blob/main/packages/pcm/README.md).

Each README keeps what the definition can't say: why it exists, first-run steps, gotchas, how
it ties to the others. Its images, ports, data, env names and `container.yml` fields are printed
by `pcm show <name>`.
